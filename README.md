# 🎭 TheaterGuide — интерактивный гид по театрам Санкт-Петербурга

**TheaterGuide** — это мобильное приложение на React Native (Expo), которое превращает прогулку по Санкт-Петербургу в увлекательное театральное путешествие. Приложение использует GPS для отслеживания местоположения пользователя, уведомляет о приближении к историческим театрам и позволяет строить собственные маршруты с режимом навигатора.

## ✨ Основные возможности

- **Интерактивная карта:** Отображение пользователя и всех театров города на карте (с поддержкой темной и светлой темы).
- **Геозоны и уведомления:** Когда вы проходите мимо театра (в радиусе 100 метров), приложение отправляет push-уведомление с предложением узнать его историю.
- **Список театров:** Удобный каталог с фотографиями, названиями и подробным историческим описанием.
- **Построение маршрутов:** Выбирайте театры на карте в нужной последовательности, чтобы создать собственный экскурсионный маршрут.
- **Сохранение и управление:** Сохраняйте маршруты в память устройства, переключайтесь между ними и переименовывайте по своему усмотрению.
- **Режим навигатора:** Пошаговые подсказки (расстояние и направление) от текущего местоположения до следующего театра в маршруте.

## 🛠 Стек технологий

- **Фреймворк:** React Native / Expo (SDK 58)
- **Маршрутизация:** Expo Router (файловая система)
- **Карты:** `expo-yandex-mapkit`
- **Геолокация:** `expo-location`
- **Уведомления:** `expo-notifications`
- **Хранение данных:** `@react-native-async-storage/async-storage`
- **Иконки:** `lucide-react-native`
- **Язык:** TypeScript

## 🚀 Как запустить проект (для разработки)

Для запуска вам понадобятся [Node.js](https://nodejs.org/) (LTS версия) и менеджер пакетов `npm` или `yarn`.

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/artemP-is-misterP/theater-guide.git
   cd theater-guide
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   # или
   yarn install
   ```

3. **Запустите сервер разработки:**
   ```bash
   npm run start
   ```

### 📱 Тестирование через Expo Go

Самый быстрый способ посмотреть приложение — использовать приложение **Expo Go** на вашем смартфоне.

1. Установите **Expo Go** из [App Store](https://apps.apple.com/app/expo-go/id982107779) (iOS) или [Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent) (Android).
2. Убедитесь, что компьютер и телефон подключены к одной сети Wi-Fi.
3. Отсканируйте QR-код, который появится в терминале после команды `npx expo start` (на iOS — камерой, на Android — через приложение Expo Go).

> **⚠️ Важное ограничение:** В Expo Go встроены не все нативные модули. Некоторые функции (например, фоновая геолокация или специфические настройки уведомлений) могут работать с ограничениями. Для полного тестирования рекомендуется использовать Development Build.

### 🛠 Development Build (Рекомендуется для полного тестирования)

Если вам нужна максимальная производительность и поддержка всех нативных функций (например, кастомный splash screen или фоновые задачи):

```bash
# Для Android
npx expo run:android

# Для iOS (требуется macOS)
npx expo run:ios
```

## 📦 Как собрать приложение (Production APK / AAB)

Для сборки релизной версии используется облачный сервис **EAS Build** (Expo Application Services).

1. **Установите EAS CLI глобально:**
   ```bash
   npm install -g eas-cli
   ```

2. **Войдите в свой аккаунт Expo:**
   ```bash
   eas login
   ```
   *(Если аккаунта нет, его можно создать на [expo.dev](https://expo.dev/))*

3. **Настройте проект:**
   ```bash
   eas build:configure
   ```
   Эта команда создаст файл `eas.json` и свяжет ваш локальный проект с вашим аккаунтом Expo (используя `projectId`, который уже прописан в `app.json`).

4. **Запустите сборку:**
   ```bash
   # Для внутреннего тестирования (APK-файл)
   eas build -p android --profile preview

   # Для публикации в Google Play (AAB-файл)
   eas build -p android --profile production
   ```

5. **Установка:**
   После завершения сборки EAS предоставит ссылку на скачивание `.apk` файла. Вы можете скачать его на телефон и установить (не забудьте разрешить установку из неизвестных источников в настройках Android).

## 📂 Структура проекта

```
├── assets/
│   └── images/               # Изображения (иконки, splash, фото театров в .webp)
├── src/
│   ├── app/                  # Маршруты приложения (Expo Router)
│   │   ├── _layout.tsx       # Корневой layout (провайдеры темы и т.д.)
│   │   ├── index.tsx         # Главный экран (онбординг)
│   │   ├── map.tsx           # Экран карты и навигатора
│   │   └── theater-list.tsx  # Экран списка театров
│   ├── components/           # Переиспользуемые UI-компоненты
│   │   └── AppTabs.tsx       # Конфигурация нижней навигации
│   ├── constants/            # Константы и конфигурации
│   │   ├── keys.ts           # Ключи (например, для AsyncStorage)
│   │   ├── theaters.ts       # Данные о театрах (координаты, описание, фото)
│   │   └── theme.ts          # Палитра цветов (Palette)
│   ├── hooks/                # Кастомные хуки
│   │   └── useTheme.tsx     # Хук для работы с темой (светлая/тёмная)
│   └── global.css            # Глобальные стили (если используются с NativeWind)
├── .gitignore                # Исключения для Git
├── app.json                  # Конфигурация Expo (плагины, разрешения)
├── eas.json                  # Профили сборки для EAS Build
├── expo-env.d.ts             # Типы для переменных окружения Expo
├── package.json              # Зависимости и скрипты
└── package-lock.json         # Фиксация версий зависимостей
```
